# Screenshots

This folder contains the screenshots used in the documentation.

## Required Screenshots

To complete the documentation, you need to add the following screenshots:

1. **editor.png** - General view of the editor with:
   - Blocks panel visible
   - An example email in the canvas
   - Style panel open

2. **ai-generation.png** - AI generation modal showing:
   - Description field
   - Style selector
   - Generated result (optional)

## How to Create Screenshots

1. Open Visual Email Editor in Thunderbird.
2. Use the Windows Snipping Tool (`Win + Shift + S`).
3. Save the images in PNG format.
4. Recommended size: 1200x800 px.
